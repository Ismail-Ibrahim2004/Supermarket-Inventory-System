##  Project Overview

The **Supermarket Inventory System** is a desktop application designed to simplify and automate common supermarket management operations.

The system provides an intuitive interface for managing inventory items, tracking sales transactions, calculating item totals, and maintaining persistent data through a **MySQL database**.

The application is developed using **Java** and **JavaFX**, with **JDBC** used to establish communication between the application and the database.

---

##  The Problem

Traditional supermarket inventory management can become difficult when handled manually.

Common challenges include:

- Difficulty tracking available inventory items.
- Manual errors when entering or updating product information.
- Lack of efficient barcode-based item lookup.
- Difficulty tracking sales transactions.
- Repetitive calculations during sales operations.
- Limited control over different user roles and permissions.
- Risk of losing data without persistent database storage.

---

##  The Solution

The **Supermarket Inventory System** provides a centralized desktop application that helps manage inventory and sales operations efficiently.

The system allows users to:

- Add, update, delete, and search inventory items.
- Quickly identify products using barcode references.
- Track sales transactions.
- Automatically calculate item totals.
- Store and retrieve data using a MySQL database.
- Organize access according to user roles such as **Cashier** and **Manager**.
- Provide a responsive and user-friendly JavaFX interface.

## 🚀 Getting Started

### Prerequisites

Before running the application, make sure you have:

- Java JDK installed.
- IntelliJ IDEA or another Java IDE.
- MySQL Server.
- Maven.
- Git.

### Installation

Clone the repository:

```bash
git clone https://github.com/Ismail-Ibrahim2004/Supermarket-Inventory-System.git

Navigate to the project:

cd Supermarket-Inventory-System

Configure your MySQL database connection in the project.

Then build and run the application through IntelliJ IDEA or Maven.
